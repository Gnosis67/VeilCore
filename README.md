# VeilCore

Security-focused, serverless-first networking project built around Cloudflare Workers and D1.

## Status

Architecture scaffold only. Not production-ready.

## Principles

- No secrets in Git
- No dependency on the abandoned Koko deployment
- Versioned configuration and migrations
- Authentication, revocation, rate limiting, and health checks
- Clear separation of control plane and traffic plane
- Readable and auditable source code
